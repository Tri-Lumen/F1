# Fonts

`jetbrains-mono-400.woff2` and `jetbrains-mono-700.woff2` are JetBrains Mono (Regular and Bold),
© JetBrains s.r.o., https://github.com/JetBrains/JetBrainsMono.

They are subset to Basic Latin, Latin-1, Latin Extended-A, box-drawing, block elements and basic
geometric shapes (about 12 KB each) and self-hosted so the ASCII visual style never falls back to
another font. Box-drawing and block glyphs from a fallback font have different widths and break
character alignment, and Google Fonts' hosted subset omits them.
